# Luna AI Flutter Client

一个基于 Flutter 开发的专业 AI 助手客户端，支持流式聊天和 AI 图像生成。

## ✨ 特性
- **流式对话**：支持 GPT 级别的打字机实时响应效果。
- **AI 生图**：集成 DALL-E 接口，支持根据提示词生成图像。
- **相册保存**：生成的 AI 图像可一键保存至系统相册。
- **视觉分析**：支持上传图片进行视觉多模态分析。
- **深色模式**：针对暗光环境优化的 UI 交互体验。

## 🚀 快速开始
1. 确保已安装 Flutter 环境。
2. 在设置界面配置您的 API Key 和 Base URL。
3. 运行项目：
   ```bash
   flutter pub get
   flutter run
   ```
